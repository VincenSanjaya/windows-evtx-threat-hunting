# Suspicious IIS Network Connection

## Objective

Identify suspicious network connections generated by the IIS worker process.

## Data Source

Windows Sysmon Event Log

Event ID:
3

Event Type:
Network Connection

## Observed Process

Image:

C:\Windows\System32\inetsrv\w3wp.exe

User:

IIS APPPOOL\DefaultAppPool

## Suspicious Connections

RDP:

127.0.0.1:49947 -> 127.0.0.1:3389

127.0.0.1:49948 -> 127.0.0.1:3389

SMB:

127.0.0.1:49949 -> 127.0.0.1:445

127.0.0.1:49950 -> 127.0.0.1:445

## Analysis

w3wp.exe is the IIS worker process used to execute web applications.

Network communication from an IIS worker process to RDP port 3389 and SMB port 445 is unusual and should be investigated.

The behavior may indicate tunneling or pivoting activity where a compromised web application is used to access internal services.

## Potential Security Impact

Possible activity includes:

Remote service tunneling

Lateral movement

Pivoting

Abuse of a compromised web server

Access to RDP or SMB services

## MITRE ATT&CK

T1572

Protocol Tunneling

T1021.001

Remote Services: Remote Desktop Protocol

T1021.002

Remote Services: SMB/Windows Admin Shares

## Investigation Steps

Review the parent process of w3wp.exe.

Identify the web application running under the DefaultAppPool.

Review IIS logs around the same timestamp.

Search for unusual HTTP requests.

Check for command execution from w3wp.exe.

Review Sysmon Process Creation events.

Review outbound network connections from the web server.

## Remediation

Investigate the affected IIS application.

Restrict unnecessary outbound connections from web servers.

Limit access to RDP and SMB services.

Apply network segmentation.

Review web application vulnerabilities.

Monitor IIS worker processes for unusual child processes and network activity.
